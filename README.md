# Sales Analysis Dashboard - Fariya's Project

📊 End-to-end Sales Analysis using MySQL + Python + Streamlit

### Tech Stack
- MySQL (sales_analysis DB: customers, products, orders)
- Python (mysql-connector, pandas, matplotlib, streamlit)
- VS Code

### Business Queries
1. **Sales by City** - Mumbai leads with ₹2.5L+
2. **Sales by Category** - Electronics dominates (₹4.15L)
3. **Monthly Sales Trend** - Shows seasonality

### How to Run
1. Import `sales_analysis` DB in MySQL Workbench
2. Set your MySQL password in `dashboard.py`
3. Run `pip install mysql-connector-python pandas matplotlib streamlit`
4. Run `streamlit run dashboard.py`
5. Open http://localhost:8501
